# Кодирование Хаффмана

Реализация алгоритма Хаффмана на Python с визуализацией и интерактивной браузерной демонстрацией.

**Демо:** https://evgehadov.github.io/huffman-coding/

Демо открывается в браузере, устанавливать ничего не нужно.

## Возможности

- Построение дерева Хаффмана по словарю вероятностей. Если сумма вероятностей не равна 1, они нормализуются автоматически.
- Генерация префиксных двоичных кодов.
- Метрики: энтропия, средняя длина кода, эффективность, избыточность.
- Проверка входных данных: пустой словарь, не словарь, отрицательные значения, NaN, бесконечность, нулевая сумма.
- Визуализация на matplotlib (`visualization.py`).
- Интерактивная версия в браузере (`index.html`): дерево с подсветкой ветвей 0 и 1, таблица кодов, гистограмма длин, метрики, ввод своих символов и вероятностей.
- 25 unit-тестов.

## Установка и запуск

```
git clone https://github.com/evgehadov/huffman-coding.git
cd huffman-coding
pip install matplotlib
python tests.py
```

## Пример использования

```python
from huffman import encode
from visualization import render, save

probs = {"a": 0.5, "b": 0.25, "c": 0.25}

root, codes, metrics = encode(probs)
print(codes)    # коды символов
print(metrics)  # entropy, avg_length, efficiency, redundancy

fig = render(root, codes, metrics, probs)
save(fig, "tree.png")
```

## Тесты

Запуск: `python tests.py`. Тесты разбиты на семь блоков:

- класс узла дерева;
- валидация входных данных;
- построение дерева;
- генерация кодов (в том числе проверка, что коды префиксные);
- информационные метрики (в том числе соотношение H ≤ L < H + 1 между энтропией и средней длиной кода);
- визуализация;
- сквозные сценарии от вероятностей до готовой картинки.
